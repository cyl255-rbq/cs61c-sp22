1. malloc
原型：void *malloc(size_t size);
作用：分配一块连续的 size 字节的内存，不初始化，内存中的内容是未定义的（可能是之前遗留的“垃圾值”）。
参数：只需指定总字节数。
返回值：指向分配内存的指针，失败时返回 NULL。
c
int *p = (int*)malloc(10 * sizeof(int));  // 分配可存放10个int的内存，未初始化
2. calloc
原型：void *calloc(size_t nmemb, size_t size);
作用：分配一块连续内存，可容纳 nmemb 个元素，每个元素大小为 size 字节，并将所有字节初始化为 0。
参数：元素个数 + 每个元素的大小。
返回值：同 malloc，失败返回 NULL。
c
int *p = (int*)calloc(10, sizeof(int));   // 分配10个int，并全部初始化为0
与 malloc 的核心区别：
calloc 会自动清零内存；malloc 不会。
calloc 需要两个参数（数量 + 单个大小），而 malloc 只需要总大小。
对于分配大量内存，calloc 可能稍慢（因为需要额外清零），但能避免未初始化值导致的 bug。
3. memset
原型：void *memset(void *s, int c, size_t n);//这里size是sizeof(xx)*x，c是想置换的
作用：将内存区域 s 的前 n 个字节每个字节都设置为 c（c 被转换为 unsigned char 后写入）。
用途：常用于手动清零或填充已有内存（例如，重置结构体、数组等）。
注意：memset 按字节赋值，不能直接用于将 int 数组元素全部设为 1（因为每个字节变成 0x01，导致整数实际值不是 1），除非类型本身是 char。
c
int arr[10];
memset(arr, 0, sizeof(arr));   // 将整个数组清零（正确）
memset(arr, 1, sizeof(arr));   // 每个字节变成1，int值会是0x01010101，不是1
常见组合
malloc 常与 memset 配合实现清零效果，但直接用 calloc 更简洁：
c
// 方式1：malloc + memset
int *p1 = (int*)malloc(10 * sizeof(int));
memset(p1, 0, 10 * sizeof(int));
// 方式2：calloc（等价）
int *p2 = (int*)calloc(10, sizeof(int));
