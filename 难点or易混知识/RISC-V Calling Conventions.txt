6.1 我们如何向函数传递参数？
使用 8 个参数寄存器 a0 - a7。
6.2 函数如何返回数值？
使用 a0 和 a1 作为返回值寄存器。
6.3 什么是 sp？在 RISC-V 函数中应该如何使用它？
sp 代表 栈指针（Stack Pointer）。它代表了栈中“已存储数据”与“空闲空间”之间的边界。
由于栈是向下增长的，我们需要通过减去 sp 的值来创建更多空间（将栈指针下移），通过增加 sp 的值来释放空间（将栈指针移回上方）。栈的主要用途是保存（以及随后恢复）那些可能会被覆盖的寄存器数值。
6.4 在使用 jal 跳转到函数之前，调用者（Caller）需要保存哪些值？
寄存器 a0 - a7、t0 - t6 以及 ra。
6.5 在从函数返回之前，被调用者（Callee）需要恢复哪些值？
寄存器 sp、gp（全局指针）、tp（线程指针）以及 s0 - s11。
注：在本课程中我们并不经常使用 gp 和 tp。
6.6 在一个无 bug 的程序中，哪些寄存器在函数调用后保证保持不变？哪些不保证？
不保证保持不变（不安全）： 寄存器 a0 - a7、t0 - t6 和 ra。在函数调用后，这些值可能会变（这就是为什么它们必须由调用者 Caller 负责保存）。
保证保持不变（安全）： 寄存器 sp、gp、tp 和 s0 - s11。在函数调用后，这些值一定和调用前一样（这就是为什么被调用者 Callee 在返回之前必须恢复它们）。

第一步：记住栈的“物理规律”
它是内存里的一块区域：sp 本质上是一个存储内存地址的寄存器。
它是向下增长的：这是最反直觉的一点。地址减小，代表栈在“变大”；地址增加，代表栈在“缩小”。
它必须“借还平衡”：你在函数开头减了多少 sp，在函数结束前必须加回去。否则，程序就会因为找不到正确的返回地址而崩溃（这就是著名的“栈溢出”或“栈破坏”）。
第二步：掌握“入栈”与“出栈”的模板
在汇编里，我们没有 push 或 pop 指令。我们得手动操作：
1. 入栈（存东西）
假设你想把 ra 和 s0 存起来：
Code snippet
# 1. 腾地方：减小 sp（存两个 4 字节的寄存器，所以减 8）
addi sp, sp, -8
# 2. 放东西：把寄存器的值存进刚才腾出的空间
sw ra, 0(sp)     # 存在 sp 指向的位置
sw s0, 4(sp)     # 存在 sp + 4 的位置
2. 出栈（取东西）
当你函数执行完了，要把刚才的东西拿回来：
Code snippet
# 1. 拿东西：按照刚才存的地址读回来
lw ra, 0(sp)
lw s0, 4(sp)
# 2. 还地方：把 sp 加回去，让这个空间变回“空闲”
addi sp, sp, 8
