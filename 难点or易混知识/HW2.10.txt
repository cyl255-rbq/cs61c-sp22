在这个程序里，判断一个块是“叶子节点（带数据）”还是“中间节点（带指针）”的唯一标准就是代码里的那个函数：
bool isleaf(Inttree* t) { return !(t->left); }
1. 结构体的大小与布局
首先，你要知道 Inttree 结构体在 64 位系统上占 16 字节：
前 8 字节：struct tree* left（左子树指针）。
后 8 字节：union { ... } rd（联合体，存右子树指针 或 整数数据）。
2. 内存中的“生死判别式”
当你在 GDB 的堆内存（Heap）里看到一个 16 字节的块时，直接看它的前 8 个字节：
情况 A：前 8 字节全部是 0
含义：left == NULL。
结论：这是一个 叶子节点 (Leaf)。
下一步：去读该块的后 8 个字节，把它当成 int data 读出来。
例子（看你的 GDB Dump）：
地址 0x555555757320：
0x555555757320: 0x00000000  0x00000000  0x00000006  0x00000000
前 8 字节是 0。判定：叶子。
后 8 字节（拼回来）是 0x0000000000000006。数据：6。
情况 B：前 8 字节不是 0
含义：left 指向了另一个地址。
结论：这是一个 中间节点 (Internal Node)。
下一步：
前 8 字节是左子树的地址。
后 8 字节不再是数据，而是右子树的地址（rd.right）。你得顺着这两个地址继续往下找。
例子（看你的 GDB Dump）：
地址 0x5555557577f0（根节点）：
0x5555557577f0: 0x55757340  0x00005555  0x557572e0  0x00005555
前 8 字节是 0x0000555555757340。判定：中间节点。
这意味着：左孩子在 0x...7340，右孩子在 0x...72e0。
即：“要不然就是 maketree（左右都有），要不然就是左边 NULL 右边 val（叶子）”。
