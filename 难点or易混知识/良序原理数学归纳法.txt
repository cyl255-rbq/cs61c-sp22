1. 假设“数学归纳法”为真，来证明良序定理
这是最常见的做法。在很多教科书里，我们先承认数学归纳法是自然数的公理（皮亚诺公理的一部分），然后去证明良序定理。
证明思路（反证法）：
    假设： 存在一个非空的自然数集合 S，它没有最小元素。
    定义性质 P(n)： “数字 0,1,2,…,n 都不在集合 S 中。”
    基础步骤： 0 一定不在 S 中。因为如果 0 在 S 中，那 0 就是自然数里最小的， 0 就会成为最小元素，与假设矛盾。所以 P(0) 成立。
    归纳步骤： 假设 P(n) 成立（即 0 到 n 都不在 S 中）。那么 n+1 在 S 中吗？
        如果 n+1 在 S 中，由于 0 到 n 都不在 S 中，那么 n+1 就是 S 里的最小元素。
        这又跟“没有最小元素”的假设矛盾了。
        所以 n+1 也不能在 S 中。即 P(n+1) 成立。
    结论： 根据归纳法，所有自然数都不在 S 中。这意味着 S 是个空集。
    将军： 但我们一开始假设 S 是非空的。矛盾！所以，非空集合 S 必然有最小元素。
